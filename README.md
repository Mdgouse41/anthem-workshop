# anthem-workshop
# 🇮🇳 National Anthem – Git & GitHub Workshop

A simple Flask-based web application created as part of a hands-on Git and GitHub practice workshop. This project demonstrates collaborative development, version control, branching, merging, and conflict resolution.

## 👨‍💻 Author

**Md Gouse Boy**

## 📌 Project Overview

This project displays the Indian National Anthem, *Jana Gana Mana*, using a basic Flask web application.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- Git
- GitHub

## ✨ Features

- Displays the Indian National Anthem.
- Simple HTML-based interface.
- Flask application structure.
- Collaborative development using Git.
- Branch creation and merging.
- Merge conflict resolution.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Mdgouse41/anthem-workshop.git
```

### 2. Navigate to the Project

```bash
cd anthem-workshop
```

### 3. Install Flask

```bash
pip install flask
```

### 4. Run the Application

```bash
python app.py
```

Open the local URL displayed in your terminal.

## 📚 Learning Outcomes

- Understanding Git fundamentals.
- Creating and managing branches.
- Committing and pushing changes.
- Collaborating through GitHub.
- Resolving merge conflicts.
- Using `git reset` and `git reflog`.
